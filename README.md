# Annora · Hexapod orbital study

[Open the interactive preview](https://kyle-annora.github.io/annora-hexapod-orbit/). Drag around the Hexapod to inspect the track in perspective. Select a bead for Leg motion or Electronics, or use the named Chapters menu. Station names appear below the canvas on hover. Both actions last 2.5 seconds and support pause, replay, scrubbing and manual camera control.

[Compare layered tracks on the front right leg](https://kyle-annora.github.io/annora-hexapod-orbit/?study=leg-orbit#leg). Select Lift, Reach or Return to hold a pose, then switch between Single and Layered using the same camera.

This repository hosts the static GitHub Pages build. [Source, local build instructions and model credits](https://github.com/kyle-annora/annora-explorer/tree/733eed0/orbit-preview). See [LICENSES.txt](LICENSES.txt) for the bundled notices.
