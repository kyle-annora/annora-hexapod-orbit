# Annora · Hexapod orbital study

[Open the interactive preview](https://kyle-annora.github.io/annora-hexapod-orbit/). Choose Leg motion or Electronics from the orbit. Both actions last 2.5 seconds and support pause, replay, scrubbing and manual camera control.

This repository hosts the static GitHub Pages build. [Source, local build instructions and model credits](https://github.com/kyle-annora/annora-explorer/tree/1109bbb/orbit-preview). See [LICENSES.txt](LICENSES.txt) for the bundled notices.
